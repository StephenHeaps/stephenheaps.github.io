Opaque origin frames

Each row reports a frame's origin, fingerprinting values, scriptlets, cosmetic filtering and request blocking. Rows prefixed initiator/ are frames created by a cross-origin iframe from the initiator domain, so their initiator origin differs from the main frame. Fingerprint cells are green when they match the main frame and red when they differ.

scriptlet / cosmetic list which rules applied: generic, main (main domain rules) or initiator (initiator domain rules).

request blocking (all) uses a plain fetch(string), which every blocking layer sees, including the iOS JS request blocking check. content blocker only (iOS) uses fetch(new URL(...)), which the iOS JS check skips, so only WKContentRuleList rules apply. On desktop both columns should match.
