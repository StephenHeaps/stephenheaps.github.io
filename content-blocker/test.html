Content blocker $third-party in cross-site frames

The top frame and a cross-site iframe each load the same scripts from both domains with <script> tags, so only content blocker rules apply. cb-any.js is blocked everywhere and confirms the rules are active. cb-3p.js is blocked only when $third-party matches.

A $third-party request should be judged against the frame that made it: a frame loading cb-3p.js from its own domain is first party and should load. If the iframe's results match the main document expectation instead, the content blocker is judging every request against the top-level site.
